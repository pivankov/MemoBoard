# MemoBoard — расширение для браузера

Расширение MV3 для создания закладок MemoBoard из текущей открытой страницы или URL из буфера обмена.

## Использование

1. Открыть страницу, которую нужно сохранить в закладки, и кликнуть по иконке расширения.
2. Поле URL по умолчанию заполняется адресом текущей открытой вкладки.
3. Кнопка «Вставить из буфера» заменяет значение в поле на содержимое буфера обмена (если это корректный http/https URL).
4. Кнопка «Отправить» создаёт закладку; попап закрывается сразу после успешной отправки, подтверждение приходит системным уведомлением.

## Установка (Яндекс.Браузер / другие Chromium-браузеры)

1. Открыть `browser://extensions` (или Меню → Дополнения → в конце списка «Режим разработчика»).
2. Включить «Режим разработчика».
3. Нажать «Загрузить распакованное расширение» → выбрать папку `extension/`.
4. Иконка расширения появится на панели инструментов; клик открывает попап.

## Настройка ключа

1. В веб-интерфейсе MemoBoard на главной странице нажать «Сгенерировать ключ для расширения».
2. Скопировать показанный ключ (`mb_pat_...`) — он показывается только один раз.
3. В попапе расширения вставить ключ в поле и нажать «Сохранить».

## Base URL

Базовый URL API зашит в `config.js` (`http://localhost:4000`). Страницы настроек нет.

Для прод-домена:
- заменить значение `API_BASE_URL` в `config.js`;
- добавить домен в `host_permissions` манифеста (`manifest.json`), например `"https://<домен>/*"`.

## Совместимость

Расширению нужны рабочие MV3 service worker, `activeTab` (для чтения URL текущей вкладки) и `navigator.clipboard.readText()` в попапе (для кнопки «Вставить из буфера»). Проверить работоспособность service worker и отсутствие ошибок при загрузке можно на странице `browser://extensions` (ссылка «service worker» у расширения открывает консоль).
