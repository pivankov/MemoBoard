# MemoBoard

> Ваш персональный онлайн-ассистент для повышения продуктивности

MemoBoard — это удобный веб-сервис для управления повседневными задачами: календарь событий с поддержкой повторений, закладки браузера и другие полезные инструменты для организации жизни.

---

## 📋 Ключевые возможности

### 🎉 События (Календарь)
- **Типы событий**: праздники, дни рождения, церковные события, прочее
- **Повторения**: разовые, ежемесячные, ежегодные события
- **Умная группировка**: автоматическая группировка по месяцам
- **Прошедшие события**: отображение недавно прошедших событий (1-7 дней)
- **Просроченные события**: отслеживание пропущенных разовых событий

### 🔖 Закладки
- Управление браузерными закладками (в разработке)

## 🛠 Технологический стек

### Frontend
- **React 18+** — библиотека для построения UI
- **TypeScript 4.9+** — типизированный JavaScript
- **Ant Design 5.x** — UI-компоненты
- **React Router 7** — маршрутизация
- **Jest** — тестирование

### Backend
- **Node.js 18+** — серверная платформа
- **Express 5** — веб-фреймворк
- **SQLite 3** — база данных
- **better-sqlite3** — синхронный драйвер для SQLite
- **Argon2** — хеширование паролей

## 🚀 Начало работы

### Требования
- **Node.js** 18.0.0 или выше
- **npm** 8.0.0 или выше

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/MemoBoard.git
   cd MemoBoard
   ```

2. **Установите зависимости backend**
   ```bash
   cd backend
   npm install
   ```

3. **Установите зависимости frontend**
   ```bash
   cd ../frontend
   npm install
   ```

### Настройка базы данных

Инициализация БД с тестовыми данными:
```bash
cd backend
npm run db:init
```

Инициализация БД без тестовых данных:
```bash
npm run db:init:noseed
```

Полный сброс БД (удаление и пересоздание):
```bash
npm run db:reset
```

### Запуск проекта

#### Режим разработки

1. **Запустите backend** (из папки `backend/`):
   ```bash
   npm start
   ```
   Сервер запустится на `http://localhost:3001`

2. **Запустите frontend** (из папки `frontend/`):
   ```bash
   npm start
   ```
   Приложение откроется на `http://localhost:3000`

#### Production сборка

1. **Соберите frontend**:
   ```bash
   cd frontend
   npm run build
   ```
   Сборка будет создана в `backend/public/`

2. **Запустите сервер**:
   ```bash
   cd backend
   npm start
   ```
   Приложение доступно на `http://localhost:3001`

## 💻 Разработка

### Frontend команды

```bash
# Запуск dev сервера
npm start

# Сборка production
npm run build

# Запуск тестов
npm test

# Запуск тестов с покрытием
npm test -- --coverage

# Линтинг
npm run lint

# Автоисправление линтера
npm run lint:fix
```

### Backend команды

```bash
# Запуск сервера
npm start

# Инициализация БД с сидами
npm run db:init

# Инициализация БД без сидов
npm run db:init:noseed

# Полный сброс БД с сидами
npm run db:reset

# Полный сброс БД без сидов
npm run db:reset:noseed
```

### Тестирование

Проект использует Jest для unit-тестирования:

```bash
cd frontend
npm test
```

**Структура тестов**:
- Файлы тестов: `*.test.ts`, `*.test.tsx`
- Расположение: в папках `__tests__/`
- Хелперы: в папках `__tests-helpers__/`
